# Zaid Nagori — Portfolio Website

A responsive personal portfolio built with Next.js App Router, React, TypeScript, Lucide icons, and custom CSS. The design uses a dark navy/blue hero with light content sections.

## Run locally

1. Install Node.js (LTS).
2. Extract this project and open its folder in VS Code.
3. Open a terminal in the project folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Visit http://localhost:3000

## Before publishing

Search in `app/page.tsx` for `ADD_YOUR_EMAIL_HERE` and replace it with your actual email. Update the LinkedIn link, and add your verified GitHub, résumé, and live project URLs. Replace the illustrated profile placeholder with your own photo if desired.

## Deploy

Push the project to GitHub and import the repository into Vercel. Use the default Next.js build settings.
